- 引证经文：疏钞中引用其他经典（非当前所释经）作为佐证的经文片段。处理方式：加引号。
- 古德言论：引用祖师、论师等前贤的言论（如无著、天亲等）。处理方式：加引号。
- 疏主释文：注疏作者自己的解释文字（如“解曰”“述曰”后的内容）。处理方式：不加引号。
- 科判：文本中隐含的层次划分标志（如“初、次、后”“一、二、三”等）。处理方式：作为分段依据。

一、体例性规则（必须优先遵守）
规则0：分段总则
- 基本单位：以一则完整的义理论述或一个独立的科判小节为自然段落。
- 结构优先：优先识别文本中隐含的科判层级（如“初、次、后”“一、二、三”），以此作为划分段落的重要依据。每个主要层级下的内容可独立成段。
- 牒文独立成段：凡疏钞中引述所释经文片段（即“牒文”），必须独立成段，以区别于下方的释文段落。牒文内容不用引号标出。（具体执行详见规则1）
- 长度控制：单段长度尽量控制在500字以内。若语意连贯且超长，可依其内在的义理转折、所引经文与注疏的转换等划分为多段，并在段首标注“【接续】”。


规则1：牒文独立成段（最核心规则）

- 定义：牒文指疏钞中引述的所释经文片段，是注疏的核心对象，后接解释文字。
- 处理要求：
  - 凡牒文必须独立成段，以区别于下方的释文段落。
  - 牒文内容不加引号（因其已通过独立成段实现视觉区分）。
- 示例：
  - 输入：如是我聞解云此六字者乃證信序也
  - 输出：
  如是我聞
  解云：此六字者，乃證信序也。
    
规则2：科判层级识别

- 优先识别文本中隐含的科判标志，作为分段依据：
  - 层级标志：“初、次、后”“一、二、三”“甲、乙、丙”等
  - 每一主要层级下的内容可独立成段
  - 次级内容可换行以体现层次
- 示例：
  - 输入：初釋經題經題云金剛般若波羅蜜經今釋此題分二一釋別名二釋通名
  - 输出：
  初、釋經題：
    經題云“金剛般若波羅蜜經”。
    今釋此題，分二：
      一、釋別名；
      二、釋通名。
    
规则3：经、论、疏三层区分
- 牒文（所释经文）：独立成段，不加引号。示例：如是我聞
- 引证经文（引他经佐证）：加引号。示例：故《大論》云：“般若譬如金剛。”
- 论典引文（无著、天亲等）：加引号。示例：無著云：“金剛難壞。”
- 古德言论（其他祖师）：加引号。示例：肇公曰：“般若者，智慧也。”
- 疏主释文（作者自述）：不加引号。示例：解云：此六字者，乃證信序也。

二、标点符号规范

规则4：引号使用（核心规则）

4.1 引号形式
- 双引号统一使用“ ”，不使用「」；单引号统一使用‘’，不使用『』。
  
4.2 区分“作者叙述”与“引用文本”
- 作者叙述不加引号：包括“解曰”“述曰”“疏曰”“钞曰”“谓”（表解释时）等引导词及其后的解释文字。
- 引用文本必须加引号：包括引证经文、论典引文、古德言论、其他典籍。
  
4.3 牒文不加引号
- 牒文已依规则1独立成段，不再重复加引号。
  
4.4 直接引语
- 所有直接引用内容均使用双引号“ ”标出。
- 通过“云”“曰”“述”“言”“谓”（当“谓”表引用义时）等词明确引文起止。
  
4.5 嵌套引语
- 引语之内再有引语，使用单引号‘ ’。
- 示例：云：“論曰：‘般若者，到彼岸慧。’”
  
4.6 自问自答不加引号
- 文中设问与作答（如“问：……答：……”）属于作者叙述，问句和答句主体部分不加引号。
- 若问句或答句中包含直接引用，被引用部分仍需加引号。
- 示例：
  - 正确：問：何名般若？答：智慧也。
  - 错误：問：“何名般若？”答：“智慧也。”
  - 正确（含引用）：問：經云“金剛”者何義？答：此喻堅利。
    
4.7 正文解释性文字的处理
- 疏主在释文中对字词、名相的连续解释（如“某者，甲也，乙也，丙也”），应作为正文连贯叙述，使用顿号、逗号分隔，不得添加括号。
- 示例：
  - 正确：“往”者，去也、起也、動也。
  - 错误：“往”者，去也（去也），起也（起也），動也（動也）。

4.8 正误对比（分类型列举）
- 作者叙述：
  - 正确：解云：此六字者，乃證信序也。
  - 错误：解云：“此六字者，乃證信序也。”
- 引用言论：
  - 正确：無著云：“金剛難壞。”
  - 错误：無著云：金剛難壞。
- 牒文（独立成段）：
  - 正确：
  如是我聞
解云：……
  - 错误：“如是我聞”解云：“……”（未分段或引号混乱）
- 自问自答：
  - 正确：問：何名般若？答：智慧也。
  - 错误：問：“何名般若？”答：“智慧也。”
- 含引用自问：
  - 正确：問：經云“金剛”者何義？答：此喻堅利。
  - 错误：問：經云金剛者何義？答：此喻堅利。
- 嵌套引语：
  - 正确：疏主釋云：“論曰：‘般若者，到彼岸慧。’”
  - 错误：疏主釋云：論曰：般若者，到彼岸慧。

规则5：冒号使用

5.1 禁止冒号叠用
- 禁止“甲：乙：……”的连续格式（两个冒号间无其他标点或引导性词语）。
- 错误示例：僧问：师曰：佛法如灯。
  
5.2 合法嵌套结构
- 在引导清晰的嵌套引语中，第二个冒号作为引语内部标点，是合法的。
- 正确示例1：僧問：“師曰：‘佛法如燈。’”
- 正确示例2：僧問：師曰：“佛法如燈。”
  
5.3 换行策略（处理多层领属关系）
- 若行文结构需要连续使用冒号表示多层领属关系（如科判层级下的分项列举），但直接连续使用属于禁止情形时，采用换行方式区分层次。
- 操作方法：第一层冒号后另起一行，再使用第二层冒号引出下文。
- 错误示例：初、释经題：經題云：金剛般若波羅蜜經。
- 正确示例：
初、釋經題：
  經題云：金剛般若波羅蜜經。
  
规则6：分号使用（层级规则）

- 标点停顿层级：顿号 < 逗号 < 分号。
- 禁止滥用：分号仅用于连接内部已包含逗号或顿号的并列分句。
- 简单并列用逗号：一是破執，二是顯性，三是明用。
- 复杂并列用分号：
一者、為破我法二執，故說此經；二者、為遮斷種現二疑，故說此經；三者、為轉滅輕重二業，故說此經。

规则7：专有名词

- 连续列举的人名、地名、佛号等，中间用顿号分隔。
- 示例：舍利弗、目犍連、須菩提
  
规则8：书名号

- 所有经典、论典、注疏、著述名称，使用书名号《》。
- 示例：《金剛經》《無著論》《智度論》
  
规则9：引号/书名号并列

- 连续出现的独立引语或书名，其间不使用顿号。
- 示例：
  - 经文“如是我聞”“一時佛在”
  - 典籍《金剛經》《心經》
    
规则10：序数词后标点

- “第X”型（第一、第二）：凡出现“第”字后接数字（无论汉字或阿拉伯数字）的序数词，其后必须使用逗号，不得使用顿号。“第”字是判断的关键标识。
  - 正确示例：第一，辯教起因緣。第二，釋經題。
  - 错误示例：第一、辯教起因緣。第二、釋經題。
  - 其他序数词示例：一、明建立之因，二、顯經宗趣。甲、總標，乙、別釋。
  【注】即使有前置符号，序数词后仍应使用逗号。
  输入：△第二約本末釋者
  输出：△第二，約本末釋者
- 其他序数词（一、二、甲、乙）：序数词后使用顿号。
  - 示例：一、明建立之因。

三、特殊文体处理

规则11：偈颂处理

11.1 独立分段
- 除作为夹注出现（括号内）的偈颂、诗赞外，所有偈颂、诗赞均须独立成段。
  
11.2 段落单位
- 以四句为一个自然段落（符合佛经偈颂典型格式）。
  
11.3 特殊处理
- 若偈颂总句数非四的倍数（二句、六句、八句等），按原有句数自然成段。
- 长篇偈颂（八句以上），依四句一组换行，组间可空一行。
  
11.4 轻断标点
- 主要使用逗号、句号进行基本断句，保持原有韵律，不做过细切分。
- 示例：
稽首牟尼大覺尊，能開般若三空句。
發起流通諸上士，冥資所述契群機。
  
  （八句长偈）
  稽首牟尼大覺尊，能開般若三空句。
  發起流通諸上士，冥資所述契群機。
  
  第二組首句，第二組二句。
  第二組三句，第二組四句。
  
规则12：小注/夹注处理

12.1 定义
- 指文中对字词、人物、名相、异文、义理等所做的解释性或校勘性文字，非正文内容。以括号形式穿插于正文中。
  
12.2 句内括号与句外括号的判断
- 句内括号：注释句中某一局部词语，必须紧跟被注词后。
- 句外括号：注释前面整个句子或语段，位于被注句的句末点号之后。
  
12.3 标点执行标准（分类型说明）
- 句内括号：括号内通常不用句末点号（问号、叹号除外）；主句句末点号置于括号外。
  - 示例：此係古德（指某已故高僧）常用之機鋒。
- 句外括号：括号内若为完整句子，保留其句末点号；括号外不再添加任何句末点号。
  - 正确示例：華嚴論“未離兜率，巳降王宮；未出母胎，度人巳畢。”（徑山杲頌云：“利刃有蜜不須舐，蠱毒之家水莫嘗。不舐不嘗俱不犯，端然衣錦自還鄉。”）
  - 错误示例：……度人巳畢。”（……還鄉。”）。 （括号外多了一个句号）

12.4 对原文括号的保守处理
- 若原文括号使用符合规范，按上述规则添加标点。
- 若原文括号使用不规范（如应为句外括号但置于句中，或括号未闭合），切勿直接修改原文括号或擅自增删括号，仅在【说明】中注明。

12.5 对疑似小注的无括号内容
- 切勿主动添加括号，保持原貌。
- 疏主释文中的解释性词语（如“某者，甲也、乙也”），属于正文叙述，应使用顿号、逗号等标点疏通文气，不得添加括号。
- 仅在【说明】中注明“某处文字（引用原文）疑似为补充说明，建议复核”。

四、特殊符号处理
规则13：○、△等古籍符号处理
13.1 符号含义
- △（空心三角形）：科判标记，用于标示新的科判层次开始，如“初、次、后”“一、二、三”等层级。其作用相当于现代排版中的章节标题。
- ○（空心圆圈）：分段或间隔标记，用于分隔较大的章节、主题转换或区分经与疏，功能类似现代排版中的空行或分隔线。
13.2 处理要求
- 原样保留：所有○、△符号必须原样保留，不可删除、替换或省略。它们是古籍固有的结构标记，对理解文本层次有重要意义。
- 标点配合：符号后正常使用现代标点（如逗号、句号），符号本身不替代标点。即符号后应紧跟标点（如需），或保留符号与正文之间的原有空格（若有）。
- 不额外解释：正文中无需对符号添加注释，除非在【说明】中需要说明特殊情况（如符号位置明显错误）。
13.3 示例
- 输入：初文二初证信序二发起序○今初证信序。
- 输出：初文二：初、證信序，二、發起序。○今初證信序。
- 输入：△文二初戒尔时世尊食时…
- 输出：△文二：初、戒。爾時，世尊食時…

五、输出规范

规则14：输出格式

14.1 主体输出
- 直接输出经标点、分段后的全文。
- 分段清晰，牒文独立成段，科判层次通过换行体现。
  
14.2 文末说明
- 如有括号问题或疑似小注的判断，在全文后空一行。
- 以“【说明】”开头，清晰列出具体位置（引用原文片段）与建议。
  
规则15：示例（典型）

示例1：牒文独立成段 + 作者叙述
- 输入：如是我聞解云此六字者乃證信序也言如是者指所聞法我聞者表能聞人
- 输出：
如是我聞
解云：此六字者，乃證信序也。言“如是”者，指所聞法；“我聞”者，表能聞人。
【说明】：无。
  
示例2：引号嵌套 + 三层区分
- 输入：無著云金剛難壞又云金剛能斷疏主釋云論曰般若者到彼岸慧
- 输出：
無著云：“金剛難壞。”又云：“金剛能斷。”
云：“論曰：‘般若者，到彼岸慧。’”
【说明】：无。
  
示例3：冒号换行 + 科判层次
- 输入：初釋經題經題云金剛般若波羅蜜經今釋此題分二一釋別名二釋通名
- 输出：
初、釋經題：
  經題云：金剛般若波羅蜜經。
  今釋此題，分二：
    一、釋別名；
    二、釋通名。
【说明】：无。
  
示例4：偈颂处理
- 输入：稽首牟尼大覺尊能開般若三空句發起流通諸上士冥資所述契群機
- 输出：
稽首牟尼大覺尊，能開般若三空句。發起流通諸上士，冥資所述契群機。
【说明】：无。
  
示例5：自问自答
- 输入：問何名般若答智慧也
- 输出：問：何名般若？答：智慧也。
【说明】：无。
  
示例6：括号处理（不规范）
- 输入：僧問如何是祖師西來意師曰庭前柏樹子（趙州語
- 输出：
僧問：“如何是祖師西來意？”師曰：“庭前柏樹子（趙州語。”
【说明】：“庭前柏樹子（趙州語”處，括號內容“趙州語”疑似為補充說明，但括號未閉合。建議覆核原文，若為小注，應補充閉合括號並標點。
  
规则16：附加要求
- 严格保持原文繁体字，不进行任何简化。
- 使用全角中式标点（，。、；：“”《》）。
- 对原文明显的讹误（如错字）、脱漏或疑义处，保持原貌，不予擅改。
